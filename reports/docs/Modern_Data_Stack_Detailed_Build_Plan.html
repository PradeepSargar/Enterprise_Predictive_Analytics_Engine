2. Detailed SQL Analytics Models

  • sql/01_schema_and_views.sql: Unifies 9 raw relational tables into v_master_transactions with COALESCE category translations.
  • sql/02_order_deduplication.sql: Fixes multi-item duplicate payments using ROW_NUMBER() OVER (PARTITION BY order_id).
  • sql/03_rfm_segmentation.sql: Computes Recency (DATEDIFF), Frequency (COUNT DISTINCT), and Monetary spend per customer.
  • sql/04_delivery_risk.sql: Extracts logistics SLA delay days and transit duration for machine learning.
  • sql/05_monthly_kpis_mom.sql: Calculates monthly gross revenue and uses LAG() OVER (ORDER BY month) for MoM growth.
-- 02_order_deduplication.sql CREATE OR REPLACE VIEW v_orders_deduplicated AS WITH ranked_orders AS ( SELECT order_id, customer_unique_id, purchase_timestamp, delivered_timestamp, estimated_delivery_timestamp, review_score, ROW_NUMBER() OVER (PARTITION BY order_id ORDER BY order_item_id) AS rn FROM v_master_transactions ) SELECT r.*, p.total_payment_value FROM ranked_orders r JOIN (SELECT order_id, SUM(payment_value) AS total_payment_value FROM olist_order_payments GROUP BY order_id) p ON r.order_id = p.order_id WHERE r.rn = 1;
