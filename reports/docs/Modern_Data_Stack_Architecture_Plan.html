Enterprise Predictive Analytics Engine

Modern Data Stack Architecture Plan & Portfolio Blueprint

1. Executive Summary

This plan outlines the enterprise-grade Modern Data Stack (MDS) architecture for the Enterprise Predictive Analytics Engine. Built on 113,425 e-commerce transactions across 9 relational tables from Olist Brazil, this design integrates SQL Data Modeling (DuckDB), Machine Learning (scikit-learn, Prophet), and an Interactive 8-Page Streamlit Dashboard.

2. Architecture Layers Overview

Layer Technology Core Responsibility
1. Raw Storage 9 Relational CSVs Transactional order items, payments, reviews, customers, sellers, and geolocation.
2. SQL / In-Process OLAP DuckDB + SQL Layer Executes relational joins, multi-item order deduplication (ROW_NUMBER), and RFM CTE modeling.
3. Machine Learning scikit-learn & Prophet Random Forest dissatisfaction classifier (83.5% Acc), K-Means RFM clustering (k=4), and 6-month revenue forecast.
4. Caching & Access Parquet & Streamlit Cache High-performance columnar Parquet files and in-memory caches (@st.cache_data / @st.cache_resource).
5. Business Intelligence Streamlit (8 Pages) Executive KPIs, real-time risk simulator, cohort retention heatmaps, and SQL data explorer.

3. The 5 SQL Analytics Models (sql/ Directory)

  • 01_schema_and_views.sql: Unified transactional base view joining all 9 tables with NULL coalescing.
  • 02_order_deduplication.sql: Uses ROW_NUMBER() OVER (PARTITION BY order_id) to eliminate duplicate payments and review scores from multi-item orders.
  • 03_rfm_customer_segmentation.sql: Multi-CTE query calculating Recency, Frequency, and Monetary metrics per customer.
  • 04_delivery_performance.sql: Extracts logistics SLA delay days and transit duration for ML risk classification.
  • 05_monthly_kpis_and_mom.sql: Computes monthly revenue and uses LAG() OVER (ORDER BY month) for Month-over-Month growth rates.

Sample SQL Query (RFM Segmentation):

WITH customer_orders AS ( SELECT customer_unique_id, order_id, purchase_timestamp, total_payment_value FROM v_orders_deduplicated ) SELECT customer_unique_id, DATEDIFF('day', MAX(purchase_timestamp), TIMESTAMP '2018-09-01 00:00:00') AS recency, COUNT(DISTINCT order_id) AS frequency, ROUND(SUM(total_payment_value), 2) AS monetary FROM customer_orders GROUP BY customer_unique_id;
